# First sweep after the uid fix to level/carry shaping (catches no longer pay).
# run-exp-v2 and v3 plateaued at mean wave ~40 (many runs die to the wave-50 boss). Their clipfrac
# fell to 0 only because the LR decays linearly to 0; at full LR it was ~0.035. This varies the
# entropy bonus and learning rate, including a constant 5e-4, and the boss-readiness reward
# (--boss-coef). Most runs start from run-exp-v2; the "bc" runs start from the behaviour-cloned
# run policy, which never learned to farm catches.
# No --ball-cost: run-exp-v5 (v3 +) cut throws from 0.47 to 0.14 per command but
# evaluated worse (41.2 vs 44.5): catches are how fainted team members get replaced. Throws at the
# wave-50 End-biome boss are already impossible. --boss-coef applies only at every 50th wave.
# The double-battle arms test the "seek doubles for carry EXP" tip; no policy had taken a lure.
# Each line: NAME train_ppo.py-args. Needs runs/run-exp-v2 and runs/bc-run synced to the cluster.
# 10M steps is ~4.5 h at the local rate (650 steps/s with 12 envs).
